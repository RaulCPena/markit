# MarkIt

Highlight text anywhere on macOS and it's copied automatically — no
⌘C needed. Right-click → Paste then works immediately, anywhere.

Includes a small clipboard history (default hotkey ⌘⇧V) and per-app
exclusions, since auto-copy makes clobbering the clipboard more
frequent.

Free and open source. Not sandboxed / not on the Mac App Store — it
needs Accessibility permission and a global event tap to work, which
the sandbox doesn't allow.
